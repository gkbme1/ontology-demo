> **V1.1 相对初稿的主要修订**
> 1. 设备范围由 A～F 改为 A～K：本体中水解反应釜组声明 11 台实例（A～K）；DCS 液位测点只覆盖 A～F（SJGYW_A～F），G～K 无在线液位。
> 2. pH 调节介质由「碱液」改为「氨水」：本工段按 pH 经氨水计量罐动态滴加氨水（AIC-1301 → 氨水调节阀 HV_1302 → 各罐氨水进料阀 XV_1304x），无碱液加注系统。
> 3. 温度调节以「热水伴热」为主（TIC-1301 → 热水阀 HV_1301、各罐热水阀 XV_1307x）；本体中未登记冷却介质，降温手段为减小 / 切断热水、控制进料温度，见附录 C。

> 5. 每台水解罐有双 pH 电极（AT_1301x1 / x2），增加双电极偏差判断。
> 6. 各报警补充：DCS 位号、报警限值、可能原因的验证方法与判据、按岗位分工的处置步骤、禁止操作、解除条件、汇报要点，以及多报警关联判断（第七章）。
> 7. 标「待现场确认」的数值与做法，在企业正式 SOP 中确认前不得作为操作依据。

## 一、目的

规范酶法水解工段异常报警的识别、原因排查与处置，做到：先确认真假、再验证原因、按原因处置、处置有记录，减少异常对酶活、水解转化率和 6-APA 收率的影响，保障生产稳定。

## 二、适用范围

适用于水解罐 A～K 进料（RB、硼酸缓冲液）、反应（温度、pH、搅拌）、终点判定、压料出料等环节出现的异常报警；以及直接影响水解罐的公用与辅助系统：热水、压缩空气、氨水计量罐、RB 储罐 A/B、硼酸罐 A/B、水解液缓冲罐。

## 三、职责

| 岗位 | 职责 |
|---|---|
| 中控主操 | 报警确认、真假判别、DCS 侧参数核对与调节、程序（SFC）暂停 / 恢复、汇报与记录 |
| 中控副操 | 协助调取趋势与历史数据、对比多测点、联系外操与相关岗位 |
| 外操 | 现场核查阀门、搅拌、管线、计量罐、就地仪表，取样复核 |
| 班长 | 重要 / 紧急报警的处置决策、升级上报、恢复确认 |
| 工艺技术人员 | 终点异常、重复报警、需调整工艺参数时的技术判断 |
| 仪表 / 设备维修 | 测点、阀门、电机、电极的检查与维修 |

## 四、异常报警处理基本原则

1. **先确认、后处置**：发现报警后确认报警罐号、报警参数、当前批次所处阶段（进料 / 反应 / 终点 / 出料）。
2. **不凭单一测点判断**：同一工艺量有多个测点的（双 pH 电极、多罐同类测点、流量与累计量与计量罐液位），先对比再判断，区分仪表故障与真实异常。
3. **按原因处置**：优先排查热水、氨水、RB / 硼酸供料、压缩空气等公用介质与对应调节阀，再查单罐设备。
4. **程序与联锁**：涉及进料、加氨、出料的操作按批次调度程序（SFC）执行；需中断时使用「暂停」，不得以强制复位、旁路联锁的方式消除报警。
5. **不擅自恢复**：异常原因及恢复条件未确认前，不得解除报警或重新启动相关程序。
6. **及时升级**：无法判断或无法及时处理的，立即报告班长及工艺技术人员。

## 七、异常报警及处置方法

每类报警按「触发 → 现象 → 可能原因（验证方法与判据）→ 处置步骤 → 禁止操作 → 解除条件 → 汇报要点」编写。可能原因按「先查共性、再查单罐」排列。

### 7.1 水解罐温度异常（ARP-S11-01 温度高 / ARP-S11-02 温度低）

**触发**：TI_1301x 超出 PL001（水解反应期）—— 正常 33～35 ℃；H 35.5 / HH 37；L 32 / LL 30（待现场确认）。

**现象**：DCS 温度高 / 低限报警；严重时多台罐同时报警。

**可能原因**

| 类别 | 原因 | 验证方法 | 判据 |
|---|---|---|---|
| 仪表 | 温度测点故障 | 看 TI_1301x 质量码与趋势，对比同期其他罐温度 | 质量码坏、数值冻结或突变，与其他罐偏差大且无工艺原因 |
| 仪表 / 设备 | 温度控制回路异常 | TIC-1301 手自动状态与设定值；HV_1301 指令与反馈 | TIC 未投自动、设定值不当；阀指令与反馈不一致或到限位 |
| 设备 | 单罐热水阀异常 | XV_1307x 阀位 | 温度高时阀位全开且关不小；温度低时打不开 |
| 工艺 | RB 进料温度高（温度高） | TI_1303 趋势（PL042：≤35 ℃） | RB 进料温度 > 35 ℃ 且早于罐温上升（R-S11-10） |
| 工艺 | 硼酸温度异常 | TE_9004 趋势 | 与罐温同向变化且早于罐温 |
| 工艺 | 热水供应异常（温度低） | 热水罐出水温度、多罐温度是否同时下降 | 多罐同时偏低，HV_1301 开大仍不回升 |
| 设备 | 搅拌异常导致温度分布不均 | P_1303x_RUN 与 P_1303x_FL | 搅拌停或故障（见 7.4） |

**处置步骤**

| 阶段 | 岗位 | 步骤 |
|---|---|---|
| 确认判断 | 中控主操 | 1. 确认报警罐号、当前阶段与 TI_1301x 当前值及 30 min 趋势；对比其他罐温度：单罐偏离查单罐，多罐同时偏离查公用（热水、RB 进料温度、TIC-1301） |
| 确认判断 | 中控主操 | 2. 按上表逐项核对 TIC-1301 / HV_1301、XV_1307x、TI_1303、TE_9004、搅拌状态，判断原因类别 |
| 假报警处置 | 中控主操 | 3. 判定为测点故障：通知仪表检查 TI_1301x，期间以趋势、同组罐温和现场就地温度监视，不据单点调节 |
| 真实处置（温度高） | 中控主操 | 4. TIC-1301 设定值核对无误后减小热水：必要时切手动关小 HV_1301，或关闭该罐热水阀 XV_1307x |
| 真实处置（温度高） | 中控主操 | 5. 因 RB 进料温度高引起的：经 SFC 暂停该罐 RB 进料，通知前工序（RB 储罐、热水伴热）降低进料温度 |
| 真实处置（温度高） | 外操 | 6. 现场检查热水阀实际开度、热水管线与伴热，确认搅拌运行 |
| 真实处置（温度低） | 中控主操 / 外操 | 7. 检查热水供应与 HV_1301、XV_1307x 是否打开；热水供应不足时联系热水岗位 |
| 升级上报 | 班长 | 8. 温度达 HH（37 ℃）或超 35 ℃ 持续不回落：暂停该罐后续进料，通知工艺技术人员评估酶活影响（R-S11-01） |
| 恢复确认 | 中控主操 | 9. 温度回到 33～35 ℃ 并稳定后，经班长确认恢复进料 / 反应，记录超温时长 |

**禁止操作**：不得在未确认原因时反复复位温度报警；不得用关闭搅拌的方式「稳定」温度读数。

**解除条件**：TI_1301x 恢复至 33～35 ℃ 并保持稳定（稳定时长待现场确认），报警自动复位。

**汇报要点**：罐号、TI_1301x 最高 / 最低值及超限时长、判定原因、TI_1303 / HV_1301 状态、已采取措施。

**影响**：超温导致固定化酶热变性失活（>35 ℃）、6-APA 母环开环降解加速；温度低则反应速率下降、终点延后。

### 7.2 水解罐 pH 异常（ARP-S11-03 pH 高 / ARP-S11-04 pH 低；含双电极偏差、加氨无响应）

**触发**：AT_1301x1 / x2 超出 PL002（水解反应期）—— 正常 7.8～8.2；H 8.4 / HH 8.8；L 7.5 / LL 7.0（待现场确认）。关联报警事件「水解pH不合格」。

**现象**：DCS pH 高 / 低限报警，罐状态显示「PH不合格」；可伴随「双 pH 计偏差」（R-S11-03）或「加氨无响应」（R-S11-04）。

**可能原因**

| 类别 | 原因 | 验证方法 | 判据 |
|---|---|---|---|
| 仪表 | pH 电极漂移 / 污染 | 对比 AT_1301x1 与 AT_1301x2；人工取样复核 | 双电极偏差超阈值且持续 > 5 min（R-S11-03）；取样值与一支电极一致 |
| 工艺 | 加氨不足（pH 低） | 氨水计量罐 LT_1302 液位变化、HV_1302 开度、XV_1304x 阀位 | HV_1302 有开度但计量罐液位 5 min 内无下降（R-S11-04：管路 / 阀堵或计量罐空） |
| 工艺 | 加氨过量（pH 高） | AIC-1301 手自动与设定值、HV_1302 开度 | AIC 设定偏高或阀开度持续偏大、计量罐液位下降过快 |
| 设备 | 氨水调节阀 / 进料阀异常 | HV_1302_AO 指令与反馈；XV_1304x_DO 与 VAL2 | 指令与反馈不一致 |
| 工艺 | 反应产酸变化 | 氨水累计加量趋势（反应进度） | 反应初期产酸快，pH 下行属正常波动，应在控制范围内回稳 |

**处置步骤**

| 阶段 | 岗位 | 步骤 |
|---|---|---|
| 确认判断 | 中控主操 | 1. 确认罐号与 pH 趋势，对比双电极 AT_1301x1 / x2 |
| 确认判断 | 中控主操 | 2. 双电极偏差大：按仪表原因处置（第 3 步）；双电极一致：核对 AIC-1301、HV_1302、XV_1304x 与氨水计量罐液位，判断加氨不足或过量 |
| 假报警处置 | 中控主操 / 外操 | 3. 通知外操人工取样复核 pH；通知仪表清洗 / 校准电极；期间以取样值为准，不按故障电极调节加氨 |
| 真实处置（pH 低） | 中控主操 | 4. 计量罐液位不降：检查计量罐是否空罐、XV_1304x 是否打开、管路是否堵（外操现场） |
| 真实处置（pH 低） | 中控主操 | 5. 恢复加氨后小幅调节，避免短时间大量补加氨水造成 pH 冲高 |
| 真实处置（pH 高） | 中控主操 | 6. 暂停该罐加氨（AIC-1301 切手动关小 HV_1302 或关闭 XV_1304x），核对 AIC 设定值 |
| 升级上报 | 班长 | 7. pH 达 HH（8.8）或 LL（7.0），或加氨无响应无法及时恢复：报告工艺技术人员评估降解 / 酶活影响 |
| 恢复确认 | 中控主操 | 8. pH 回到 7.8～8.2 并经取样复核后，恢复自动加氨与后续反应 |

**禁止操作**：不得以单支故障电极的读数调节加氨；不得在 pH 偏低时一次性大量补加氨水。

**解除条件**：双电极均恢复至 7.8～8.2 且偏差在允许范围内，取样复核一致。

**汇报要点**：罐号、AT_1301x1 / x2 读数及偏差、取样值、计量罐液位变化、HV_1302 开度、判定原因。

**影响**：pH 偏离 7.8～8.2 酶催化速率下降；pH > 8.5 碱性开环降解加剧。

### 7.3 RB 进料异常（ARP-S11-05 RB 进料温度高 / ARP-S11-06 RB 进料量异常）

**触发**：RB 进料温度 TI_1303 > 35 ℃（PL042，H 35.5）；或进料过程中 FT_1302A / B 流量异常下降、中断，累计量未达设定值（PL011 数值待现场提供）。

**可能原因**

| 类别 | 原因 | 验证方法 | 判据 |
|---|---|---|---|
| 工艺 | RB 储罐液位低 / 供料不足 | RB 储罐 A / B 液位 | 液位低于进料要求 |
| 设备 | RB 打料泵未运行或不打量 | RB 液打料泵 A / B 运行信号、出口压力 | 泵停或出口压力低 |
| 仪表 / 设备 | 进料调节回路异常 | FIC-1302A / B 状态；HV_1308 / HV_1309 指令与反馈 | 阀未开或指令反馈不一致 |
| 设备 | 单罐 RB 进料阀未开 | XV_1302x_DO 与 XV_1302x_VAL2 | 有开指令无开到位反馈 |
| 仪表 | 流量计异常 | FT_1302A / B 与罐液位 SJGYW_x 变化对比 | 流量为 0 但液位在涨，或反之 |
| 操作 / 程序 | SFC 进料程序中断 | 批次调度程序状态、当前罐号 | 程序暂停 / 报错 |
| 工艺（温度高） | RB 预热 / 伴热过热 | 热水罐出水温度 | 热水温度升高带动 TI_1303 升高 |

**处置步骤**

| 阶段 | 岗位 | 步骤 |
|---|---|---|
| 确认判断 | 中控主操 | 1. 确认对应罐号、SFC 进料程序状态、FT_1302A / B 瞬时流量与累计量、设定加量 |
| 确认判断 | 中控主操 | 2. 对比流量与罐液位变化（A～F 用 SJGYW_x），判断是计量问题还是实际进料异常 |
| 真实处置 | 中控主操 / 外操 | 3. 依次检查 RB 储罐液位、打料泵运行与出口压力、HV_1308 / HV_1309 与 XV_1302x 阀位，外操现场确认管线 |
| 真实处置（温度高） | 中控主操 | 4. TI_1303 > 35 ℃：经 SFC 暂停 RB 进料，联系前工序降低 RB 温度，防止拉高罐温（R-S11-10 → R-S11-01） |
| 恢复确认 | 中控主操 | 5. 排除异常后按程序恢复要求继续进料；核对累计进料量满足批次要求后记录 |

**禁止操作**：不得在 RB 进料温度 > 35 ℃ 时继续进料；不得手动强开阀门绕过 SFC 程序进料。

**解除条件**：TI_1303 ≤ 35 ℃；流量恢复、累计进料量达设定值。

### 7.4 搅拌运行异常（ARP-S11-07 反应期搅拌停止）

**触发**：反应期 P_1303x_RUN = 0 持续 > 2 min（R-S11-07），或 P_1303x_FL 故障、运行反馈与启停指令 P_1303x_DO 不一致。

**可能原因**：电机故障 / 过载保护动作（P_1303x_FL）；电源或控制回路异常；远程 / 就地状态切换（P_1303x_RM）；机械卡阻；反馈信号异常。

**处置步骤**

| 阶段 | 岗位 | 步骤 |
|---|---|---|
| 确认判断 | 中控主操 | 1. 核对 P_1303x_DO 指令、P_1303x_RUN 反馈、P_1303x_FL 故障、P_1303x_RM 远程状态 |
| 真实处置 | 外操 | 2. 现场确认搅拌是否实际停转、电机保护是否动作、就地 / 远程开关位置 |
| 真实处置 | 中控主操 | 3. 搅拌停止期间评估对反应的影响，必要时经 SFC 暂停该罐进料与加氨（传质不足会导致 pH / 温度分布不均） |
| 升级上报 | 班长 | 4. 联系设备维修；故障短时无法排除时通知工艺技术人员 |
| 恢复确认 | 中控主操 | 5. 故障排除并经设备、工艺确认后重新启动搅拌，确认 RUN 反馈正常 |

**禁止操作**：故障原因未排除前不得反复启动搅拌电机；不得在保护动作后强行复位启动。

**解除条件**：P_1303x_RUN = 1 且与指令一致，P_1303x_FL 复位。

**影响**：传质不足，pH / 温度分布不均；剪切过大（频繁启停）会造成酶颗粒破碎、载体寿命下降。

### 7.5 水解终点异常（ARP-S11-08 终点判定异常 / 氨耗偏低）

**触发**：
- 终点判定：氨水计量罐液位下降速率 ≈ 0 持续超过阈值，且 pH 稳定在正常区间（R-S11-05，提示可出料）；
- 异常：批次结束时氨水累计加量低于按 RB 投料量折算的理论氨耗 × 下限系数（R-S11-06）；或达到预定时间后取样残留青霉素 G 偏高、6-APA 指标不达标。

**可能原因**：反应时间不足；酶活下降；温度或 pH 曾偏离规定范围；RB 等物料实际加入量异常；搅拌效果不佳；分析偏差。

**处置步骤**

| 阶段 | 岗位 | 步骤 |
|---|---|---|
| 确认判断 | 中控主操 | 1. 暂停后续出料程序，保持物料状态 |
| 确认判断 | 中控副操 | 2. 调取本批次 TI_1301x、AT_1301x1 / x2、氨水累计加量、RB 累计进料量、搅拌运行的全过程历史，与正常批次对比 |
| 确认判断 | 外操 / 化验 | 3. 复核取样与分析，必要时重新取样 |
| 真实处置 | 工艺技术人员 | 4. 核对酶制剂使用记录与酶活；按意见决定延长反应或其他措施 |
| 恢复确认 | 班长 | 5. 指标达标后确认进入出料 |

**禁止操作**：终点未确认不得出料；不得仅凭反应时间判定终点。

---

### 7.6 出料异常（ARP-S11-09 出料压力不足 / ARP-S11-10 水解液缓冲罐高位）

**触发**：出料程序启动后 XV_1308x_FT 无流量、罐液位不下降；或出料中 PT_1301 低于低限（R-S11-09，PL044 待现场提供，关联报警「压缩空气压力低出料注意」）；或 LT_1303 高于高限（R-S11-08，PL043 待现场提供，关联报警「水解液缓冲罐高位报警」）。

**可能原因**

| 类别 | 原因 | 验证方法 | 判据 |
|---|---|---|---|
| 公用工程 | 压缩空气压力不足 | PT_1301 趋势 | 低于低限，多罐出料同时偏慢 |
| 工艺 | 下游缓冲罐高位 / 不接收 | LT_1303、水解液泵调节阀 SJGAB / SJGCD / SJGEF | 缓冲罐高位，萃取进料中断导致不出料 |
| 设备 | 出料切断阀未开 | 水解罐进出料气动切断阀状态 | 有指令无开到位 |
| 设备 | 管线堵塞 | 罐压与液位变化 | 压料压力正常但液位不降 |
| 仪表 | 出料流量检测异常 | XV_1308x_FT 与罐液位对比 | 液位在降但无流量信号 |
| 操作 / 程序 | SFC 出料程序异常 | 当前输出罐号、程序状态 | 程序暂停或输出罐号不对 |

**处置步骤**

| 阶段 | 岗位 | 步骤 |
|---|---|---|
| 确认判断 | 中控主操 | 1. 确认 SFC 当前输出罐号与程序状态；对比罐液位下降与 XV_1308x_FT |
| 确认判断 | 中控主操 | 2. 查 PT_1301 与 LT_1303：多罐出料慢且 PT_1301 低，查压缩空气；LT_1303 高，查下游萃取接收 |
| 真实处置 | 中控主操 | 3. LT_1303 高位：暂停水解出料（R-S11-08），联系萃取岗位确认进料是否中断 |
| 真实处置 | 外操 | 4. 现场检查出料切断阀、管线与压缩空气管路 |
| 恢复确认 | 中控主操 | 5. 排除后按程序恢复出料，确认出料完成并记录 |

**禁止操作**：缓冲罐高位时不得继续强行出料；不得为加快出料擅自提高压料压力超出规定值。

## 八、多报警关联判断

多个报警同时出现时，先按下表判断是否同一根源，只对根源报警按对应条款处置，其余报警跟踪确认随根源恢复。

| 同时出现的报警 | 可能的共同根源 | 先查 |
|---|---|---|
| 多台罐温度同时高 | TIC-1301 / HV_1301 异常，或 RB 进料温度高 | TIC-1301 状态、HV_1301 指令与反馈、TI_1303 |
| 多台罐温度同时低 | 热水供应不足 | 热水罐出水温度、HV_1301 |
| 多台罐 pH 同时低 + 加氨无响应 | 氨水计量罐空罐或公用加氨管路堵 | LT_1302 各计量罐液位、HV_1302 |
| 单罐 pH 异常 + 双电极偏差 | 该罐电极故障 | AT_1301x1 / x2 对比、取样 |
| 单罐温度、pH 同时波动 + 搅拌停 | 该罐搅拌故障 | P_1303x_RUN / FL |
| 多罐出料慢 + PT_1301 低 | 压缩空气不足 | PT_1301、空压站 |
| 出料慢 + LT_1303 高 | 下游萃取不接收 | LT_1303、萃取进料 |
| 罐温高 + RB 进料超温 | RB 进料温度高 | TI_1303、热水伴热 |

## 十、异常升级处理要求

1. 一般报警：当班操作人员检查处理并记录。
2. 重复报警：同一设备或同一参数在一个班次内重复出现（次数待现场确认），通知班长及工艺技术人员分析；仪表原因反复出现的，列入报警治理清单。
3. 严重异常：温度 HH / LL、pH HH / LL 持续，或涉及设备损坏、物料泄漏，按现场应急及停车规程执行。
4. 无法确认原因的异常：不得通过反复复位、强制操作、旁路联锁消除报警，联系相关专业人员处理。
5. 异常恢复后：确认参数、设备及程序运行正常，由规定的责任人员确认后恢复生产。
