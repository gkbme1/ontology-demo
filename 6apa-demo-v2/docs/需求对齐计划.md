# 需求对齐计划（对照《工业本体模型 系统需求规格 V0.5》）

原则：需求中有、Demo 中没有的直接补；两边都有但不一致的，按更合适的一方改（多数按需求，Demo 更贴合现场的保留并在此说明）。
开发态修改触发工程态更新（类库更新同步）不做。每批做完给用户看过再做下一批。

保留 Demo 做法（建议反向修订需求文档）：

- 判定规则保留 `change`（由 A 变 B）运算和「计算组态输出」作条件主体；
- 参数约束保留「限值版本」（按换酶后批次等条件生效）——制药场景需要，需求里没有；

## 后续批次（建议）

**第 2 批：对象详情的工程态组态**
- 参数页签：参数类别按需求（测量值 / 设定值 / 阀位 / 状态 / 计算值 / 设计值）与静态属性分开；位号绑定状态（已绑定 / 待确认 / 未绑定 / 失效）及筛选（SW-028）；
- 继承覆盖：设备上覆盖 / 禁用设备组的现象阈值、限值，一键恢复继承，来源显示「已覆盖 / 已禁用」（SW-026、SW-045、SW-046）；
- 试算：手工输入取值试算（SW-046）；
- 拓扑关系、工艺影响关系可在页签中新增 / 删除（SW-044、SW-049），端点类型校验；
- 对象基础信息与变更记录（SW-041 第 5 条、SW-062）。

**第 3 批：处置规程与计算组态**
- 处置卡拆分：可能原因 → 原因现象 + 导致关系，步骤字段按需求（前置条件、预期结果、是否需人工确认），禁止自动执行标识（SW-051）；
- 计算组态：执行方式（周期 / 事件 / 按需）、周期、超时、失败处理、输出测点；在页签中新建 / 编辑（SW-050）；
- 算法库：版本、被引用、输入输出定义（SW-013，上传与隔离执行不做）。

**第 4 批：校验与发布、数据交换**
- 发布本体版本（全量校验无错误才允许）、版本列表、两版对比、回滚（SW-060、SW-061）；页头显示当前发布版本；
- Excel 导出（全量 / 按范围）、TTL 导出（SW-067、SW-069）；
- 操作留痕（导入 / 导出 / 发布 / 删除，SW-079）。

**第 5 批：类库浏览（开发态，只读为主）与运行态**
- 类库浏览：类树、类属性、参数模板、约束 / 现象 / 根因模板、实例清单（SW-003、SW-015）；关系类型清单（附录 B，SW-010）；
- 运行查看工具：加载版本、对象与关系数量、绑定状态、失效绑定（SW-076）；
- 现象状态评估（模拟数据）与活动现象查询、知识沉淀提交与审核队列（SW-073、SW-075）。
