# 北I-2 深冷装置本体梳理（第一步：只梳理本体）

场景从 6-APA 原料药车间换成油气行业深冷装置（油气加工三大队 北I-2 深冷站）。本步只整理本体内容，**不改前后端代码**；
成果是一个 Excel：`data/cryo/北I-2深冷_本体.xlsx`。

## 数据源

| 来源 | 位置 | 用到的内容 |
|---|---|---|
| DCS 点表（和利时 MACS 导出，控制站 10 / 11） | `data/cryo/source/北I-2深冷_DCS点表.xlsx` | 3055 个点名（含备用 267），按块类型分 sheet |
| 操作规程 WJ/TRQ/03-09-04（2025.6.13） | `data/cryo/source/北I-2装置操作规程_2025.6.13.docx` | 装置概况、开停车、PID 回路、分子筛时序、现场操作、附录（运行参数、阀位、报警联锁、安全阀） |
| DCS 流程画面截图 | 仓库根目录 `深冷装置工艺流程图/`（44 张，只读） | 设备编号、画面划分、拓扑、点表未命名的通讯点 |

## 生成方式

```bash
python3 -m backend.tools.build_cryo_ontology     # 依赖 openpyxl、python-docx（离线整理工具，Demo 运行时不需要）
```

- `backend/tools/cryo_knowledge.py`：人工梳理的部分（单元、画面、设备类 / 组 / 实例、物料、拓扑、PID 回路、联锁、工况、
  工艺影响、现象与根因、能力、待确认）。要改本体内容就改这里再重新生成；
- `backend/tools/build_cryo_ontology.py`：读点表与规程，自动完成 位号 → 对象 归属、阀门实例、规程表格（限值、阀位、安全阀）、
  规程正文步骤、规程位号 → DCS 位号映射，然后组装 Excel。

## 主要待确认项（详见 Excel「待确认」）

- **设备编号冲突**：导热油炉画面 H10701 / 规程 H-10501（与轻烃外输泵 P-10501 号段冲突）；冷冻画面甲醇罐标 D10502（与二次闪蒸罐同号）；
  增压机出口分离器 D10207 / D10407 / D-10205 三种写法；火炬压力排污罐画面 D10603、规程 D-10206；三甘醇尾气撬设备与再生气系统同号。
- **设备数量**：轻烃外输泵规程 2 台、画面 / 点表 3 台；膨胀机规程只写一台、点表 A/B 两台；丙烷机附录五列了双份换热器。
- **位号**：规程 2.3 启机界定表的 104-TT-111 / 106 / 105 / 121 与点表同号点含义不同；附录四 104-PRCA-111 写「塔釜压力」而 104PT111 是塔顶；
  丙烷机、导热油炉、锅炉的通讯点（PN10_* / PN11_*）在点表里没有描述；点表报警限的当前值导出为 0，需在线导出。
- **限值**：J-T 阀设定 3.20 / 3.50 / 3.60 MPa 三处说法不一。
