# 北I-2 深冷装置本体梳理

场景从 6-APA 原料药车间换成油气行业深冷装置（油气加工三大队 北I-2 深冷站）。成果 Excel：`data/cryo/北I-2深冷_本体.xlsx`；
Demo 的数据源由它生成（`build_cryo_sources.py`，见 README「重新生成」）。

**口径（用户确认）：DCS 流程画面与点表为准；操作规程是旧版，只在画面 / 点表没有的内容上作参考。**
设备编号、台数、位号含义冲突时一律取画面 / 点表，规程编号只作别名；规程里的限值、PID 设定、处置步骤作参考值，标「草案·待工艺确认」。

## 生成方式

```bash
python3 -m backend.tools.build_cryo_ontology     # 依赖 openpyxl、python-docx（离线整理工具，Demo 运行时不需要）
```

- `backend/tools/cryo_knowledge.py`：人工梳理的部分（单元、画面、设备类 / 组 / 实例、物料、拓扑、PID 回路、联锁、工况、
  工艺影响、现象与根因、能力、待确认）。要改本体内容就改这里再重新生成；
- `backend/tools/build_cryo_ontology.py`：读点表与规程，自动完成 位号 → 对象 归属、阀门实例、规程表格（限值、阀位、安全阀）、
  规程正文步骤、规程位号 → DCS 位号映射，然后组装 Excel。

## 冲突处理（按画面 / 点表口径，详见 Excel「待确认」）

- **设备编号**：导热油炉取画面 H10701 / P10701（规程 H-10501 / P-10501）；二次闪蒸罐取 D10502；增压机出口分离器取总流程画面 D10207（冷冻画面 D10407 为别名）；
  火炬压力排污罐取 D10603；过滤分离器 / 吸附器 / 干气过滤器 / 空氮站设备取画面编号。冷冻画面甲醇罐也标 D10502（与二次闪蒸罐同号），本体编号须唯一，暂用 D10402，**待现场核实画面标号**。
- **设备数量**：轻烃外输泵按画面 / 点表 3 台；膨胀机 2 台（A/B）；丙烷机按画面 1 套。
- **位号**：限值一律挂点表位号；规程 2.3 启机界定表的 104-TT-111 / 106 / 105 / 121 与点表同号点含义不符，不挂；附录四 104-PRCA-111「塔釜压力」按点表作塔顶压力 104PT111。
- **仍需现场提供**：点表报警限当前值（导出为 0）、无描述通讯点（PN10_* / PN11_*）的含义、丙烷机通讯点、J-T 阀当前设定。
